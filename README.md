# 养老机构分药盒管理系统（medbox）

按**医嘱版本**与**餐次**准备住户分药盒，药师核对后签发，护理员按床位交接、床旁执行并记录
签收 / 拒服 / 暂缓；异常全部进入复核闭环。纯 Python 标准库实现，SQLite 保存完整签发链，
封盒照片存本地，提醒由进程内线程处理，扫码由可替换的模拟适配器返回。

## 一条命令启动

```bash
python3 -m medbox                 # 建库 + 播种停药样例 + 启动服务 http://127.0.0.1:8080
python3 -m medbox --reset --port 8099   # 清空重建样例并换端口
python3 -m medbox --seed-only     # 只建库播种，不起服务（冒烟 / CI）
```

首次启动自动生成全套样例：临时停药与版本作废、正常完成、暂缓、外出阻断、昨日漏签、拒服闭环。

## 角色与权限

| 角色 | 权限 |
|------|------|
| 医生 physician | 唯一可开立 / 停用 / 修改医嘱；停用自动产生新版本 |
| 配药员 packer | 按医嘱版本装盒、登记碎药/错格、作废未签发盒 |
| 药师 pharmacist | 也可调配；核对药名/规格/数量/禁忌后**签发**、封盒、异常复核闭环 |
| 护理员 nurse | 床位交接、床旁执行；**无权改医嘱** |

**双人复核**：装盒人与复核签发人必须不同（`SAME_PERSON` 阻断），签发链记录 `packed_by` 与 `checked_by`。

## 签发链（全部落 SQLite）

```
医嘱版本 → 装盒(固定床位×餐次格位) → 药师核对签发 → 封盒(本地照片)
        → 床位交接 → 床旁扫码执行(签收/拒服/暂缓) → 异常追踪闭环
```

## 阻断与复核规则

| 场景 | 处理 |
|------|------|
| 医嘱临时停用 | 生成新版本；仅**该住户该餐次内容实际变化**的旧盒失效，无关住户药盒不受影响 |
| 旧版药盒 | 签发、装盒、床旁执行三处均阻断（`STALE_BOX`），须药师/配药员作废后按新版重装 |
| 药片碎裂 / 错放格位 | 未补换/归位前阻断签发（`BROKEN_PILL` / `MISPLACED_CELL`），固定格位不得重叠 |
| 住户外出 | 阻断装盒与床旁执行（`RESIDENT_AWAY`） |
| 重复给药 | 数据库 `administrations.item_id UNIQUE` 兜底；终态（签收/拒服）任何再确认一律阻断，并发下也只留一条记录 |
| 扫码不符 | 模拟适配器读数与格位药品不一致即阻断（`SCAN_MISMATCH`） |
| 禁忌 | 青霉素过敏等核对阶段阻断（`CONTRAINDICATION`）并升高风险异常 |
| 拒服 | 必填原因 → 高风险异常 + 通知 → 药师复核闭环 |
| 暂缓 | 必填预计时间；到期由提醒任务通知；跟进可转签收/拒服，仍只有一条执行记录 |
| 漏签 | 超过餐次截止时间仍**完全无记录**的格位生成异常与通知（幂等） |

## 界面

- **药盒台**：按餐次 × 床位固定格位，每格始终显示药名、规格、剂量、数量；高风险用文字 +
  红色双重提示（医疗白底 + 青色主色）。
- **床旁端**：大号「已签收 / 拒服 / 暂缓」按键，顶部显示本盒剩余未执行项，扫码框预填模拟条码。
- **医嘱/住户**：医生临时停用（生成新版本）、新增医嘱、登记外出/返回。
- **异常追踪**：开放/已闭环分级列表，复核必须填写处置说明。
- **通知/流水**：进程内提醒、所有阻断与重复尝试均在 `admin_events` 留痕。

## 测试

```bash
python3 -m unittest discover -s tests -v
```

覆盖（29 项）：版本失效（含"无关版本升级不误伤"）、双人不同人签发与角色强制、
顺序与**并发**重复执行只留一条、拒服原因/高风险异常/药师闭环，以及碎药、错格、外出、
扫码、禁忌、暂缓跟进、漏签幂等、HTTP 端到端。

## 结构

```
medbox/
  db.py         SQLite 建表（签发链 + 唯一约束）
  core.py       全部领域规则与阻断逻辑
  scanner.py    扫码模拟适配器（MED:药名;规格;批号）
  photos.py     本地封盒照片（无依赖生成 PNG）
  reminders.py  进程内提醒线程（暂缓到期 / 漏签）
  seed.py       停药样例播种
  server.py     stdlib HTTP + JSON API（写操作串行化）
  static/       单页三端界面
  __main__.py   命令行入口
tests/          领域规则测试 + HTTP 集成测试
```

零第三方依赖，仅需 Python 3.10+。
